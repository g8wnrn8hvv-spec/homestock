# HomeStock

집 안의 공간을 한눈에 보는 HomeStock 첫 번째 MVP입니다. 각 공간은 독립된 SVG 영역이며, 터치로 선택하고 두 손가락으로 확대·축소·이동할 수 있습니다.

## 실행 방법

```bash
npm install
npm run dev
```

개발 서버가 안내하는 주소를 Safari에서 엽니다.

## 프로덕션 빌드

```bash
npm run build
```

빌드 결과는 `dist/` 폴더에 생성됩니다.

## PWA 설치

배포된 HTTPS 주소를 iPhone Safari에서 연 뒤 공유 버튼을 누르고 **홈 화면에 추가**를 선택합니다. 설치 후에는 독립 실행형 앱 화면으로 열립니다.
